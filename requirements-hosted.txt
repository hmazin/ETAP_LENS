# Dependencies for the hosted (container) deployment.
#
# Deliberately a standalone list rather than "-r requirements.txt", because it
# differs in two ways:
#   - no pyodbc: the hosted app serves study result files, which are plain
#     SQLite. Reading .MDF/.BAK needs SQL Server LocalDB, which is Windows-only,
#     and pulling pyodbc in would mean carrying unixODBC build headers in the
#     image for a code path that can never run there.
#   - gunicorn: POSIX-only, and the desktop app uses Flask's own server.
flask
flask-cors
olefile
openpyxl
gunicorn
google-cloud-storage
