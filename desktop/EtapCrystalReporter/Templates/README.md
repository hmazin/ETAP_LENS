Place your licensed ETAP `.rpt` templates here, or select another folder in Template settings.
Subfolders appear in the selection list, for example `Momentary / Complete`.
Templates are not embedded, modified, or supplied by this project.

An optional adjacent `Complete.rpt.json` configures explicit study compatibility, table aliases,
and scalar parameters. See `example.rpt.json.example` and the desktop setup guide.
An empty `StudyTypes` array imposes no restriction; the database schema must still match.
Do not guess engineering compatibility from a template's filename.
