ETAP Lens

Point this at an ETAP .oti, .mdf, or .bak file on the left to explore everything inside your project - buses, cables, transformers, generators, loads, and protective devices - without needing ETAP installed.

An .oti file only holds a connection pointer; this tool automatically finds and reads the real database (.MDF/.BAK) sitting next to it.

You can also load study result files the same way - pick them directly: short-circuit (.SA1S ANSI duty, .SA2S fault currents) or load flow (.LF1S balanced, .UL1S unbalanced/3-phase, .TU1S time-domain/TDLF - which also gets an annual AC loss report).

Paste a folder path instead of a file to scan the whole project directory - you'll get a list of everything loadable in it, and pick just the one you want. Or use Browse Folders on the left to navigate there visually.
